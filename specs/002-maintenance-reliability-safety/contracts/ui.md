# UI and domain contract

All mutators throw readable validation errors; invalid requests do not mutate state.
Open stop requires machine only (manual or simulated sensor); repeats select existing event.
Reason uses the fixed spec list. Entry needs text or photo, stamps selected technician.
LOTO applies per source and confirms zero energy independently; remove retains applier.
Only supervisor authorizes release. Operator confirms first good part with optional time.
Technician closes when all missing items are satisfied; refusal enumerates omissions.
Handover acknowledgment stamps current shift and captures active locks; only a current-shift
technician/supervisor can acknowledge prior-shift work. Overdue begins exactly 30 minutes in.
Verification: first full shift starts at/after first good part, ends eight calendar hours later.
Matching stop before that end reopens earlier repair even if reason is entered afterward.
No route or backend contracts: machine/history selection stays on one static page.
